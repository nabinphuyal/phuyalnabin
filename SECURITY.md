# Security Policy

## Supported Versions

यो project सधैं **latest version** मा मात्र security update पाउँछ।

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

यदि तपाईंले यो project मा कुनै security vulnerability फेला पार्नुभयो भने, कृपया निम्न माध्यमबाट report गर्नुहोस्:

📧 **Email:** [nabinkanxo5@gmail.com]

**कृपया ध्यान दिनुहोस्:**
- Public issue नबनाउनुहोस् — यसले अरू प्रयोगकर्ताको data खतरामा पार्न सक्छ
- Vulnerability को विस्तृत विवरण, steps to reproduce, र सम्भावित impact पठाउनुहोस्
- म **48 घण्टाभित्र** reply गर्नेछु
- Fix हुनुभन्दा पहिले vulnerability publicly disclose नगर्नुहोस्

## Response Timeline

- **24-48 घण्टा:** Initial acknowledgment
- **7 दिन:** Vulnerability assessment र fix plan
- **30 दिन:** Fix release

धन्यवाद! तपाईंको responsible disclosure ले यो project सुरक्षित राख्न मद्दत गर्छ।
